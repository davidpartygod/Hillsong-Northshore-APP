# Hillsong Northshore Scheduler v4.4 Setup

## 1. Create Supabase Project

Create a free Supabase project.

In the project dashboard, copy:

- Project URL
- anon public key

They are under:

`Project Settings -> API`

## 2. Create Database Table

Open:

`SQL Editor`

Paste and run:

`supabase-schema-v4.4.sql`

This creates one shared `app_state` table. All authenticated users can read and write it for now.

## 3. Configure Auth

Go to:

`Authentication -> Providers -> Email`

Email/password auth is fine for v4.4.

If email confirmation is on, users must confirm their email before logging in.

## 4. Configure indexv4.4.html

Open `indexv4.4.html` and replace:

```js
const SUPABASE_URL = "YOUR_SUPABASE_PROJECT_URL";
const SUPABASE_ANON_KEY = "YOUR_SUPABASE_ANON_PUBLIC_KEY";
```

with your Supabase values.

## 5. GitHub Pages

Push `indexv4.4.html` to GitHub.

In GitHub repo settings:

`Settings -> Pages`

Publish from your main branch.

## 6. Supabase URL Allow List

In Supabase:

`Authentication -> URL Configuration`

Add your GitHub Pages URL as a site/redirect URL if needed.

Example:

`https://yourname.github.io`

## Notes

v4.4 keeps the data model simple: one shared JSON document for the whole scheduler.

Later versions can split this into relational tables for events, services, modules, and user roles.
